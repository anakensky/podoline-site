# ПодоЛайн — сайт студии подологии

Одностраничный сайт студии подологии «ПодоЛайн» (Комсомольск-на-Амуре, проспект Копылова, 33).
Обычный статичный сайт: HTML, JavaScript и картинки, без сборки и без сервера.

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Сама страница со всеми текстами, ценами и контактами |
| `js/main.js` | Анимации при прокрутке, прогулка по кабинету, стопка отзывов, отправка формы |
| `js/config.js` | Настройка: адрес сервера для заявок в Telegram |
| `images/logo.jpg` | Логотип |
| `images/valeria.jpg` | Фото мастера |
| `worker/telegram-worker.js` | Код сервера, который пересылает заявки в Telegram (на GitHub не работает, ставится отдельно на Cloudflare) |
| `.nojekyll` | Служебный файл для GitHub Pages, удалять не нужно |

## Как выложить на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com) и нажмите **New repository**.
2. Назовите репозиторий, например `podoline`, выберите **Public** и нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите в окно **всё содержимое** этой папки: `index.html`, `README.md`, `.nojekyll` и папки `js`, `images`, `worker`. Нажмите **Commit changes**.
   Файл `.nojekyll` скрытый: если система его не показывает, ничего страшного, сайт заработает и без него.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/podoline/`.

Свой домен (например `podoline.ru`) подключается там же, в **Settings → Pages → Custom domain**.

## Заявки в Telegram

Без этого шага форма работает, но вместо отправки предлагает позвонить по телефону.

1. **Бот.** В Telegram напишите [@BotFather](https://t.me/BotFather), отправьте `/newbot` и сохраните токен.
2. **Chat ID.** Напишите своему боту любое сообщение, затем откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите число в `"chat":{"id": ...}`.
   Для группы: добавьте бота в группу, напишите в ней сообщение и сделайте то же самое.
3. **Сервер.** Зарегистрируйтесь на [cloudflare.com](https://cloudflare.com) (бесплатно), откройте **Workers & Pages → Create → Create Worker**, назовите его `podoline-form`, нажмите **Deploy**, затем **Edit code** и замените код содержимым файла `worker/telegram-worker.js`. Нажмите **Deploy**.
4. В настройках воркера (**Settings → Variables and Secrets**) добавьте:
   - `BOT_TOKEN` — токен бота, тип **Secret**;
   - `CHAT_ID` — число из шага 2;
   - `ALLOWED_ORIGIN` — адрес сайта без слэша в конце, например `https://ваш-логин.github.io`.
5. Скопируйте адрес воркера (вида `https://podoline-form.ваш-аккаунт.workers.dev`) и вставьте его в `js/config.js`:
   ```js
   window.PODOLINE_CONFIG = {
     workerUrl: 'https://podoline-form.ваш-аккаунт.workers.dev'
   };
   ```
   На GitHub это делается прямо в браузере: откройте файл, нажмите значок карандаша, исправьте и нажмите **Commit changes**.

Токен бота хранится только в Cloudflare. В коде сайта и на GitHub его быть не должно.

## Как поправить текст или цены

Все тексты лежат в `index.html`. На GitHub откройте файл, нажмите карандаш, найдите нужную фразу через Ctrl+F (на Mac Cmd+F), исправьте и нажмите **Commit changes**. Сайт обновится через минуту.

Подписи прогулки по кабинету продублированы в `js/main.js` (список `TOUR_STOPS`): если меняете их в `index.html`, поменяйте и там.
